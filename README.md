# Portfolio website

A static portfolio site (HTML, CSS, JS). No build step needed.

## Folder structure
```
portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── assets/          (put your photo, resume.pdf, screenshots here)
└── README.md
```

## Edit before publishing
In `index.html`, replace:
- `your.email@example.com` with your email
- `your-username` in the LinkedIn and GitHub links
- The About text, skills and the three project cards

## Publish on GitHub Pages (free)
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (public).
2. Upload all files and folders from this folder to the repository root (Add file > Upload files). `index.html` must be in the root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io`.

## Optional
- Add a resume: put `resume.pdf` in `assets/` and link `assets/resume.pdf` in the Contact section.
- Colors are variables at the top of `css/style.css`.
